# 부스 리더보드 (그래비트랙스 거북이 대회)

인터넷 없이 동작하는 단일 HTML 파일 리더보드입니다.

## 실행
`index.html`을 더블클릭해 브라우저(Chrome, Edge 등)로 엽니다. 설치나 서버가 필요 없습니다.
전체화면은 입력 탭의 ⛶ 버튼 또는 F11 키를 사용합니다.

## 화면 구성
- 왼쪽 위: 부스 이름과 설명 (번호로 시작하는 줄은 번호 뱃지로 표시)
- 왼쪽 아래: 기록 입력 탭. 이름과 기록을 넣고 Enter를 누르면 바로 반영됩니다. 아래 목록에서 수정·삭제할 수 있습니다.
- 오른쪽: 리더보드. 항상 1위부터 10위까지 표시하고, 1위가 가장 크고 아래로 갈수록 작아집니다. 1~3위는 금·은·동 색으로 강조됩니다.

## 기본 설정
- 부스 이름: 그래비트랙스 거북이 대회
- 단위: 초, 순위 기준: 기록이 클수록(오래 걸릴수록) 상위
- 같은 이름을 다시 입력하면 더 좋은 기록만 남김

⚙ 설정 버튼에서 이름, 설명, 이미지(예시 도면 등), 단위, 순위 기준, 중복 이름 처리를 바꿀 수 있습니다.

## 데이터
- 입력한 기록은 브라우저 저장소에 자동 저장되어 브라우저를 닫았다 열어도 유지됩니다.
- ⬇ 백업 버튼으로 JSON 파일을 저장하고, ⬆ 복원 버튼으로 불러올 수 있습니다. 다른 PC로 옮길 때도 이 방법을 씁니다.
- 브라우저의 "인터넷 사용 기록 삭제"로 사이트 데이터를 지우면 기록이 사라지므로 행사 끝에 꼭 백업하세요.
