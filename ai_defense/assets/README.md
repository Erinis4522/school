# 그림(에셋) 교체 안내

**캐릭터 v2 설계**([`../docs/CHARACTER_DESIGN.md`](../docs/CHARACTER_DESIGN.md)) 기준 그림 완료는 나래(궁수)·서리(빙결)·하은(표식) 3명. 검객은 v1 리그를 임시로 쓰고, 저격수·화염·번개·폭탄 4명은 그림이 올 때까지 `data/heroes.json`의 `look`으로 그린 도형 SD 인물이 나옵니다. 적·지도·기지는 아직 **도형 플레이스홀더**입니다.
아래 이름으로 PNG를 넣기만 하면 코드 수정 없이 바뀝니다. 없는 파일은 계속 도형으로 그려집니다.

## 넣는 곳 (둘 중 하나)

| 방법 | 위치 | 다시 빌드 |
|---|---|---|
| A. 운영 PC에서 바로 교체 | `AIDefense.exe` 옆 `assets/<분류>/<이름>.png` | 필요 없음 (다시 실행만) |
| B. 프로젝트에 포함 | `ai_defense/assets/<분류>/<이름>.png` | `build_exe.ps1` 다시 실행 |

같은 이름이 둘 다 있으면 A(실행 파일 옆)가 우선입니다.

## 파일 이름 (영문 소문자, 투명 배경 PNG)

| 분류 | 파일 |
|---|---|
| `heroes/` | `sword.png` 검객, `archer.png` 궁수, `sniper.png` 저격수, `fire.png` 화염술사, `ice.png` 빙결술사, `lightning.png` 번개술사, `bomb.png` 폭탄공학자, `mark.png` 표식술사 |
| `enemies/` | `normal.png`, `fast.png`, `armored.png`, `boss.png` |
| `map/` | `background.png` (20×11.25 타일 = 16:9 전체 지도, 예: 1920×1080), `base.png` 기지, `slot.png` 설치 자리 |
| `ui/` | `speech-bubble.svg`, `card-frame.svg` — 예약만 해 둠 (1차 버전은 코드로 그림) |
| `effects/` | 예약만 해 둠 (1차 버전은 도형 효과) |

`map/path.png`는 예약 이름이며, 길은 지금 `background.png` 위에 코드로 그립니다. 길까지 그려진 배경을 쓰려면 `data/game_config.json`의 `map.path` 좌표를 그림과 맞춰 주세요.

## 그림 규칙

- 정사각형 **256×256** 권장 (128×128도 가능). 그림은 가운데 정렬.
- **기준점(anchor) = 이미지 아래쪽 가운데 = 발 위치.** 발이 이미지 아래 가장자리에 닿게 그려 주세요.
- 화면 크기: 캐릭터 한 변 ≈ 1.1 타일, 적 한 변 ≈ 적 반지름 × 2.6 (보스가 가장 큼).
- 같은 캐릭터 파일을 터치 화면 카드 초상과 전투 화면에 함께 씁니다.
- 색만 다른 8명이 아니라 **실루엣·무기·머리장식**으로 구분 (PRD 7.3: 검객=둥근 방패+짧은 검, 궁수=후드+활, 저격수=긴 석궁+모노클, 화염술사=주황 망토+불꽃 지팡이, 빙결술사=하늘색 외투+얼음 결정, 번개술사=보라색 전도봉+번개 문양, 폭탄공학자=고글+공구 벨트+폭탄, 표식술사=마법 두루마리+빛나는 표식).
- 참고 게임의 그림을 추출·색 보정해서 쓰지 마세요. 아래에 출처와 라이선스를 기록해 주세요.

## 교체 확인

게임 실행 → 터치 화면 오른쪽 위 모서리 2초 길게 누르기(또는 F10) → **그림 파일 상태**: `■ PNG`는 실제 그림, `□ 도형`은 플레이스홀더.

## 출처·라이선스 기록

| 파일 | 만든 사람/출처 | 라이선스 |
|---|---|---|
| `fonts/NotoSansKR-Regular.otf` | Google Noto Sans KR | SIL OFL 1.1 (`fonts/OFL.txt`) |
| `heroes/archer·ice·mark·sword.png`, `heroes/rigs/sword/*` (검객 파츠 13조각 + rig.json) | 사용자 제공 패키지 `AI_Defense_SD_All_8_With_Parts_v1` (2026-11-11 반입) | 프로젝트 소유자 제공 |

## 현재 적용된 그림과 애니메이션

| 캐릭터 | 파일 | 움직이는 방식 |
|---|---|---|
| 검객 | `heroes/rigs/sword/` 파츠 13조각 + `rig.json` (카드용 `heroes/sword.png`) | **관절 리그**: 몸통·머리·머리카락·코트 흔들림, 왼팔-팔뚝-검을 관절별로 회전해 베기 |
| 궁수·빙결·표식 | `heroes/<이름>.png` 전신 한 장 | **통짜 변형**: 숨쉬기(늘였다 줄였다), 기울이기, 반동, 점프·회전 |
| 저격수·화염·번개·폭탄 | (그림 대기 중) `look` 값 | **도형 SD 인물**(`src/view/chibi_art.gd`)에 같은 변형 애니메이션. `heroes/<이름>.png`를 넣으면 자동으로 그림으로 바뀜 |

동작 3종 (`src/view/hero_sprite.gd`)
- **대기**: 숨쉬기 + 살짝 흔들림. 캐릭터마다 박자가 달라 함께 움직이지 않음
- **공격**: 공격할 때마다. 표적 쪽으로 몸을 돌림. 스타일별로 다름 — 검객 앞으로 베기 / 궁수·저격수 쏘는 반동 / 화염·빙결·번개·표식 지팡이를 들며 늘어남 / 폭탄 던지기
- **특기 공격**: 엔진이 "특기가 제대로 발휘된 공격"이라고 표시한 공격에서, 2.2초에 한 번까지. 웅크림 → 점프 → 착지, 검객은 공중 두 번 베기, 시전형은 한 바퀴 회전. 캐릭터 색 고리 효과 + 특기 이름 표시

| 캐릭터 | 특기 공격이 되는 순간 |
|---|---|
| 검객 | 두 명을 동시에 벰 |
| 궁수 | 이번 화살로 처치 |
| 저격수 | 갑옷·보스를 맞힘 |
| 화염술사 | 불꽃이 2명 이상에게 |
| 빙결술사 | 빠른 적을 맞힘 |
| 번개술사 | 번개가 2번 전이 |
| 폭탄공학자 | 폭발 범위에 3명 이상 |
| 표식술사 | 동료가 함께 칠 수 있는 단단한 적(또는 동료 둘 다 닿는 적)에 표식 |

이 표시는 화면 연출에만 쓰이고 전투 결과에는 영향이 없습니다.

### 그림 손질 내역
- 7종 전신 PNG는 흰 배경에서 오려 낸 흔적(흰 테두리)이 있어 `tools/defringe.gd`로 정리함
  (반투명 픽셀의 흰색 섞임 되돌리기 + 바깥 하얀 테두리 최대 2px 제거). 원본은 반입 폴더에 그대로 있음.
  새 그림을 넣을 때도 같은 문제가 있으면: `godot --headless --path . --script res://tools/defringe.gd -- assets/heroes/<이름>.png`
- 검객 리그 파츠는 단순 벡터 그림이라 나머지 7종(채색 일러스트)과 그림체가 다릅니다. 같은 형식(512 캔버스 + rig.json)으로
  다시 그린 파츠를 `heroes/rigs/sword/`에 덮어쓰면 코드 변경 없이 바뀝니다. 다른 캐릭터도 `heroes/rigs/<이름>/rig.json`과 파츠를 넣으면
  자동으로 관절 리그 방식으로 바뀝니다 (관절 각도는 현재 검객 파츠 이름 기준이라, 새 리그는 `_rig_angles` 보완 필요).

- 빌드된 exe: `AIDefense.exe -- --selfcheck=C:/temp/check` → 추천 팀으로 전투를 띄워 두 화면 스크린샷과 그림 적용 목록(`selfcheck.txt`)을 저장하고 종료
